# Completed Tasks

Archive of closed Task Records, moved out of `task_log.md` once Auditor closes a task (mirrors
`task_log.md`'s relation to `../../PLAN.md`, and this file's own relation to `completed_plan.md`).
This is a historical record — don't re-open or re-edit an entry here; a closed task found to need
more work later becomes a new Task Record instead, linked back via a `Follow-up of:` line in the
new task's `ask.md`.

Kept as one growing file for v1. If it becomes unwieldy at scale, splitting by year or quarter —
the same shape `CHANGELOG.md` already reserves for itself — is the natural next step; deferred
until there's an actual file worth splitting, not designed preemptively.
